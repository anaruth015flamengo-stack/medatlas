Como a plataforma está organizada

Cada laboratório vive em sua própria pasta. Assim, uma atualização no atlas ou no coração não apaga os demais módulos. Este site usa páginas estáticas e pode ser hospedado gratuitamente no GitHub Pages. Algumas ferramentas 3D e exames requerem internet para carregar arquivos externos.

Aviso: protótipos de uso educacional, não validados para diagnóstico ou decisões clínicas.
